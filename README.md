# Number Guessing Game

## Overview

Number Guessing Game is a Python-based command-line application where players try to guess a randomly generated number between 1 and 100.

The game provides hints after each attempt and dynamically adjusts the guessing range to help the player find the correct answer.

## Features

- Random number generation
- Interactive user input
- Dynamic range adjustment
- Hint system (Too High / Too Low)
- Attempt counter
- Win detection and result display

## Technologies Used

- Python
- Random Module

## Concepts Applied

- Loops
- Conditional Statements
- User Input Handling
- Random Number Generation
- Variables and Counters
